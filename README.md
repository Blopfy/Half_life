# 3D Marble Run (Onshape)

A 3D marble run CAD model created in **Onshape**. This project explores 2D sketching, construction planes, profile cross-sections, and sweeping geometry to build marble tracks and assemblies.

## Project Overview

- **CAD Software:** Onshape (`marble_run`)
- **Core Modeling Workflow:** 2D Sketch → Cross-Section Face → Sweep along Path / Construction Planes

## Modeling Notes

- **2D Sketches & Profiles:** Start with 2D sketches to define the track cross-section and path geometry.
- **Planes & Paths:** Use reference planes and sketch edges to guide track curves and transitions.
- **Sweep Feature:** Sweep a 2D face along a selected sketch path edge to generate 3D track channels.
- **Assembly & Iteration:** Combine track sections, supports, and catch/runout features into a complete marble run layout.

## How to View / Open in Onshape

1. Open **Onshape** in your browser.
2. Open the **`marble_run`** document (`Main` workspace / `Part Studio 1` and `Assembly 1`).
3. Export parts or assemblies (e.g., `.STL` or `.STEP`) if you want to 3D print or inspect them in another CAD tool.
